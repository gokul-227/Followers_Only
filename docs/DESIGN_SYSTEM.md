# FollowersOnly design system

Original identity: a violet orbit enclosing a single spark, paired with the FollowersOnly wordmark. No reference logos, imagery or source assets are used.

- Ink #252238, muted #777487, canvas #f8f7fb, white panels, border #ece9f2, primary #7652e8, accent #e9e1ff, success #21745f.
- System sans body, geometric bold headings, 15px body, 12px metadata. Spacious editorial headings balance compact social content.
- 4px spacing scale; 12/20/28px panel rhythm, 18px cards and 999px pills. Thin borders, restrained shadows, purple focus ring.
- Desktop: 232px navigation, 640px primary column, 300px discovery rail. Tablet collapses rail and navigation labels; mobile uses five-item bottom navigation and a navigation sheet for remaining destinations.
- Avatar initials and original abstract local artwork are fictional seed assets. Creator covers use geometric gradients. No remote image dependency.
- Lucide line icons; visible action labels and accessible names for icon-only controls. Native dialog for confirmation/media viewer; details menu for post actions.
- Forms have explicit labels, inline server errors, disabled pending submission, and success feedback only after persistence.
- Skeletons, empty-state orbit illustration, lock card, unread dot, toast/status region and retry panels are shared components.

These are independent product decisions. The research verified general navigation and control patterns, not these exact visual measurements.
